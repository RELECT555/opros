# Повторная проверка приветственного экрана

Дата: 2 ноября 2026. Область: классический welcome, начало заполнения, декоративная волна и управление движением. Проверка выполнялась на локальном `__preview_crm`; реальные API и сохранение ответов не проверены.

## Проверенные проблемы и исправления

| Приоритет | Место | Что обнаружено | Исправление |
| --- | --- | --- | --- |
| Высокий | `survey/index.html` | Русскоязычный интерфейс объявлял `lang=en` | `lang=ru`; мобильный viewport учитывает safe area |
| Средний | Welcome → форма | Фокус выбирал первый контрол по глобальному селектору и таймеру | `SurveyFormEntry` фокусирует заголовок первого вопроса при монтировании формы |
| Средний | Форма, 320 px | Панель шагов и режимов раздвигала layout до 370 px | Перенос элементов topbar; повторно измерено `clientWidth=scrollWidth=320` |
| Средний | `WelcomeIntro` | Пользовательский логотип без текстового имени | Добавлен alt для логотипа организатора; знак Askly рядом с текстом остаётся декоративным |
| Средний | `DottedSurface` | Ошибка создания WebGL могла прервать показ опроса | Без WebGL декоративный слой пропускается; работоспособность CTA проверена с подменой WebGL-контекста на недоступный |
| Средний | `DottedSurface` | Скорость зависела от частоты кадров, фоновая вкладка продолжала цикл | Расчёт по времени, остановка в скрытой вкладке, ограничение скачка времени при возврате и pixel ratio до 2 |
| Низкий | Переключатель фона | Доступное имя менялось вместе с pressed state | Стабильное имя «Анимация фона», состояние через `aria-pressed` |
| Низкий | Welcome CSS | Накопились повторные правила, отменяющие друг друга | Собраны единые правила и media queries, убран ненужный `!important`, исправлены safe-area отступы |

## Проверки и ограничения

- UIMax: 0 автоматических a11y-нарушений, 33 пройденных правила, 1 пункт требует ручной оценки. Скриншоты 375/768/1440 px получены; проверка 320 px дополнена измерением layout viewport, а не только `innerWidth`.
- Chrome DevTools: Tab → Enter открывает форму, активный элемент — H3 первого вопроса; после переноса панели у формы нет горизонтального переполнения на 320 px.
- Проверка отказа WebGL: welcome и кнопка остаются в DOM, canvas отсутствует; после восстановления WebGL и переключения фона кадры снова различаются.
- Детерминированный `21st review`: 0 findings. TypeScript, целевой ESLint и 4 целевых теста проходят; production build проходит с существующим предупреждением большого bundle.
- Общий lint по-прежнему не принимается как зелёный: ранее получено 17 существующих ошибок вне новых компонентов. Реальные аккаунты/данные не создавались.
- UIMax помечает native button с onClick как отсутствие клавиатуры: ложное срабатывание, Tab/Enter проверены вручную. Empty alt у знака Askly рядом с именем корректен; lazy loading логотипа первого экрана не требуется.
- Автоматические советы про canonical/JSON-LD/социальные карточки не применялись к dev-only опросу без установленного публичного URL и требований индексации. `lang=en`, напротив, являлся реальным дефектом и исправлен.
- Lighthouse не завершился; UIMax получил dev LCP около 2.67 с и CLS 0. Эти числа не доказывают ни production-регрессию, ни production-ускорение; field-данные отсутствуют.
- Нет подтверждения реальным экранным диктором и физическим мобильным устройством. Авторизованный canvas editor и production API остаются вне принятой проверки.

Список «О чём вас спросим» получает реальные заголовки из настроек опроса. В `__preview_crm` это демонстрационные данные. Респондент отвечает в форме после CTA; список на welcome — только предварительный обзор.
